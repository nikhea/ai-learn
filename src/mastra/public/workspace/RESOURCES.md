# Modern LLM & AI Engineering Resources

## Knowledge

### Prompt Engineering
- [Prompt Engineering Guide](https://www.promptingguide.ai/)
  The definitive resource for all prompting techniques. Use for: understanding prompting fundamentals, advanced techniques (CoT, few-shot, chain-of-thought), and model-specific guidance.

- [Savas Labs: Best Practices for LLM Powered Solutions](https://savaslabs.com/blog/best-practices-llm-powered-solutions)
  Practical guide for building with LLMs. Use for: understanding when to use prompting vs RAG vs fine-tuning, workflow design, and production considerations.

- [OpenAI Prompt Engineering Guide](https://platform.openai.com/docs/guides/prompt-engineering)
  Official guidance from OpenAI. Use for: best practices specific to OpenAI models.

### AI Agents
- [AI Agents Guide - Prompt Engineering Guide](https://www.promptingguide.ai/agents)
  Comprehensive introduction to AI agents. Use for: understanding agent architecture, function calling, and context engineering.

- [Building Effective AI Agents - DAIR.AI Course](https://academy.dair.ai/courses/building-effective-ai-agents)
  Intermediate course on agent development. Use for: hands-on agent building skills.

### RAG (Retrieval Augmented Generation)
- [RAG Research Findings](https://www.promptingguide.ai/research/rag)
  Research-backed insights on RAG. Use for: understanding RAG effectiveness and implementation patterns.

### Models & Landscape
- [LLM Collection - Prompt Engineering Guide](https://www.promptingguide.ai/models/collection)
  Curated list of available LLMs. Use for: model selection and comparison.

- [Sebastian Raschka's LLM Blog](https://sebastianraschka.com/blog)
  Deep technical analysis of LLM architectures. Use for: staying current with latest developments (more advanced).

### Safety & Best Practices
- [Adversarial Prompting Guide](https://www.promptingguide.ai/risks/adversarial)
  Understanding prompt injection, jailbreaking, and security. Use for: building secure LLM applications.

## Wisdom (Communities)

- [r/LocalLLaMA](https://reddit.com/r/LocalLLaMA)
  Community for running LLMs locally. Use for: technical discussions and troubleshooting.

- [r/AI_Agents](https://reddit.com/r/AI_Agents)
  Focused on AI agent development. Use for: agent architecture discussions and real-world implementations.

- [LangChain Discord](https://discord.gg/langchain)
  Active community for LLM app development. Use for: getting help with popular frameworks.

- [Hugging Face Discord](https://discord.gg/huggingface)
  ML community hub. Use for: model sharing and fine-tuning discussions.

- Los Angeles AI Meetups (search Meetup.com for local AI/ML groups)
  Use for: networking and real-world connection.

Setting Up an EC2 Instance for LLM Inference

Introduction

In this lesson, you'll learn how to set up an EC2 instance specifically configured for running LLM inference. This is a critical step toward building your LLM-powered application as outlined in your mission.

Prerequisites

Before proceeding, ensure you have:

  • An AWS account with appropriate permissions
  • Basic familiarity with AWS EC2 (covered in the previous lesson)
  • SSH client installed (e.g., OpenSSH on Linux/macOS or PuTTY on Windows)

Step-by-Step Guide

Step 1: Choose the Right Instance Type

For LLM inference, you'll want a balance of CPU, memory, and networking performance. Recommended instance types include:

  • General Purpose: m6g.large or m6g.xlarge (ARM-based, cost-effective)
  • Compute Optimized: c6g.large (for CPU-intensive inference)
  • Memory Optimized: r6g.large (for larger models requiring more memory)

For most LLM applications, the m6g.large instance type is a good starting point.

Step 2: Select a Deep Learning AMI

AWS provides Deep Learning AMIs (DL AMIs) that come pre-configured with popular ML frameworks. For LLM inference, you'll want to select one of these:

  • Deep Learning AMI (Ubuntu) Version 2023.03.x or later
  • Deep Learning AMI (Ubuntu) with PyTorch
  • Deep Learning AMI (Ubuntu) with TensorFlow

These AMIs come with CUDA drivers, NVIDIA libraries, and popular ML frameworks pre-installed, saving you configuration time.

Step 3: Configure Instance Details

  1. Choose the instance type you selected in Step 1
  2. Choose an existing key pair or create a new one for SSH access
  3. Configure network settings (VPC, subnet)
  4. Add storage (EBS volume size based on your model needs)
  5. Configure security group to allow SSH (port 22) and any necessary ports for your application

Step 4: Launch the Instance

Review your configuration and click "Launch Instance". AWS will provision the instance and it will be ready to connect via SSH.

Step 5: Connect to Your Instance

Use SSH to connect to your instance. The command would look something like:

ssh -i your-key.pem ubuntu@

Once connected, you'll have access to the command line on your EC2 instance.

Primary Source: AWS EC2 Launch Wizard Documentation - Official guide to launching EC2 instances

Practical Example: Running a Simple LLM Inference

Now that you have an EC2 instance running, let's test it with a simple LLM inference example. We'll use a small open-source LLM model.

  1. Connect to your EC2 instance via SSH
  2. Update your package manager: sudo apt update
  3. Install required dependencies: sudo apt install python3-pip
  4. Install a lightweight LLM library: pip3 install transformers torch
  5. Download a small LLM model (e.g., pip install transformers[torch] and use a model like "gpt2")
  6. Create a simple Python script to run inference
#!/usr/bin/env python3
from transformers import pipeline

# Load a small LLM model
classifier = pipeline("text-generation", model="gpt2")

# Run inference
result = classifier("Hello, how are you today?", max_length=50)
print(result[0]['generated_text'])

Save this as llm_inference.py and run it with python3 llm_inference.py.

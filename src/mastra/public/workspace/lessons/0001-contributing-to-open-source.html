# Your First Open Source Contribution: A Step-by-Step Guide ## Mission Help Mike contribute to an open source project to build his workflow skills. This lesson will guide you through your first contribution, giving you a tangible win in open source collaboration. ## Steps to Contribute 1. **Find a project**: Look for projects with the "first-timers-only" label on GitHub. 2. **Fork the repository**: Click the fork button on the project's GitHub page. 3. **Clone the repository**: Use `git clone https://github.com/username/project.git`. 4. **Create a branch**: `git checkout -b your-branch-name`. 5. **Make a change**: Edit a file (e.g., fix a typo in README.md). 6. **Commit and push**: `git commit -m "Fix typo"` and `git push origin your-branch-name`. 7. **Open a pull request**: Go to the original project's GitHub page and create a PR from your branch. ## Primary Source Review [GitHub's Contributing Guide](https://guides.github.com/activities/contributing-to-open-source/) for detailed best practices. ## Quiz What is step 3?
